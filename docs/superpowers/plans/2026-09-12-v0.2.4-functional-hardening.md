# Censorship v0.2.4 Functional Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the confirmed Gemini, Claude, OpenAI, and release-output defects and publish a verified `v0.2.4` release.

**Architecture:** Extend the existing byte-range selectors with explicit provider paths and two span constraints, then keep transformation and error generation centralized in `transformRequest`. Replace release destinations through same-directory temporary files and recoverable directory-entry swaps so no existing inode is truncated. Preserve the native ABI and CLIProxyAPI request-interceptor lifecycle unchanged.

**Tech Stack:** Go 1.26.0, CGO native ABI v1, `github.com/router-for-me/CLIProxyAPI/v7 v7.2.152`, `github.com/tidwall/gjson v1.18.0`, Go standard library, GitHub Actions, GitHub CLI.

**Spec:** `docs/superpowers/specs/2026-09-12-v0.2.4-functional-hardening-design.md`

## Global Constraints

- Modify only this censorship plugin repository. Do not modify CLIProxyAPI core or the Go module cache.
- Keep `C.GoBytes` in `cliproxyPluginCall`; preserve native ABI v1 ownership, length, call, free, reconfigure, and shutdown contracts.
- Keep `words` as a strict Object. Legacy sequence/global `mode` remains handwritten-YAML-only. The panel must not emit global `mode`.
- Preserve the fixed `block` -> `strip` -> `obfs` order.
- Select only documented, explicit natural-language paths. Do not add a generic recursive string walker or inspect machine fields.
- Preserve original request bytes outside changed JSON string tokens.
- Do not hand-edit generated `.integration/` or `dist/` files.
- Use the Go standard library for release-output replacement. Add no dependency.
- Make every behavior change with a focused failing test first.
- Keep the patch surgical. Do not refactor adjacent selector, configuration, ABI, or build code.
- Coding execution uses Sonnet 1M/xhigh. Spec, plan, and independent review use Opus 1M/xhigh.
- Do not load more than three files or subagent result files into one context batch.

func appendJSONSchemaDescriptions(spans *[]textSpan, schema gjson.Result, role string, roles scopeSet) {
	if !schema.IsObject() || !roles.has(role) {
		return
	}
	appendStringSpan(spans, schema.Get("description"), role, roles)

	for _, key := range []string{"properties", "patternProperties", "$defs", "definitions", "dependentSchemas"} {
		children := schema.Get(key)
		if children.IsObject() {
			children.ForEach(func(_, child gjson.Result) bool {
				appendJSONSchemaDescriptions(spans, child, role, roles)
				return true
			})
		}
	}
	for _, key := range []string{"items", "additionalProperties", "unevaluatedProperties", "propertyNames", "contains", "not", "if", "then", "else"} {

		children := schema.Get(key)
		if children.IsArray() {
			children.ForEach(func(_, child gjson.Result) bool {

	}
	if err != nil {
		return err
	}

	backup, err := reserveUnusedSibling(destination, ".backup-")

		return err
	}

		return fmt.Errorf("stage existing output %q: %w", destination, err)

		if rollbackErr := renameOutputFile(backup, destination); rollbackErr != nil {

	}
	if err := os.Remove(backup); err != nil {

	}
	return nil
